🎮 Anti-Gravity AI: Ghost in the Machine

A frictionless 2D zero-gravity interactive sandbox where Newtonian physics meets an in-browser neural "Zero-G Ghost". Built entirely in a single index.html with HTML5 Canvas, Tailwind CSS, Web Audio API synthesis, and Hugging Face's open-source Transformers.js running local client-side AI.

✨ Key Features
  • 0-G Frictionless physics with 2D elastic vector collision
  • Floating space debris, code packets, & haunted nodes
  • Spectral Ghost entity with sine bobbing & eye tracking
  • "Disturb the Ghost" kinetic impulse blast
  • Procedural Web Audio synthesizer (no sound assets)
🧠 AI Architecture
  • Transformers.js in-browser ONNX runtime
  • Eerie quantum thought stream & observation loops
  • Interactive haunted Q&A prompt interface
  • Zero server keys or tokens required
  • 100% Client-Side & privacy preserving
